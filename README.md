# AGILEproject

## 7daysTinder запуск:
1. Для запуска игры перейдите на [Google Drive по ссылке](https://drive.google.com/drive/u/0/folders/1p4MDFMwZKmHssV5QNnwHLKY0ljGWWnL_).

2. Скачайте папку в зависимости от вашей операционанной системы: -pc (Windows), -mac (Mac)

3. Откройте папку на компьютере, разархивируете и выберите файл "7daysTinder.exe"

4. Приятной игры!
