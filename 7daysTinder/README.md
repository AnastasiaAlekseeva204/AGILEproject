1. Создаем папку на компьютере, в которой будет проект
2. Клонируем туда этот репозиторий (git clone, etc)
3. Скачаем движок renpy, выбрать желаемый язык английский (по желанию)
2. В папке renpy находим и запускаем renpy.exe -> preferences -> general -> "projects directory" и добавить эту папку
3. Tinder7days будет в active projects
